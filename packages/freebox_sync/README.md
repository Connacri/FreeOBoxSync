# freebox_sync

A free, decentralized peer-to-peer (P2P) local network sync engine for **ObjectBox** Flutter & Dart applications. Uses binary transaction logs (`OBXS`) and field-level CRDTs to achieve sub-millisecond offline-first synchronization across local devices without any paid cloud subscription.

[![pub package](https://img.shields.io/pub/v/freebox_sync.svg)](https://pub.dev/packages/freebox_sync)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

---

## Features

* **100% Free & Open Source**: No device licenses, no active user fees, no cloud dependence.
* **Ultra-Low Latency (< 2ms)**: Direct peer-to-peer TCP communication on local Wi-Fi / Ethernet subnets.
* **Zero-Copy Binary Protocol**: 56-byte header + compact property deltas (88% smaller than JSON).
* **Automatic Conflict Resolution (CRDTs)**:
  * **HLC-LWW**: Last-Write-Wins with Hybrid Logical Clocks.
  * **PN-Counter**: Commutative positive-negative counters for inventory and stock.
  * **OR-Set**: Add-wins Observed-Remove sets for tags and relations.
* **Zero-Config LAN Discovery**: Devices discover each other automatically via UDP broadcast on `:8443`.
* **Anti-Echo Loop Protection**: Prevents re-broadcasting remote updates applied to the local `Box<T>`.

## Installation

Add `freebox_sync` to your `pubspec.yaml`:

```bash
flutter pub add freebox_sync
```

Or manually:

```yaml
dependencies:
  objectbox: ^4.0.0
  freebox_sync: ^1.0.0
```

## Quickstart (3 Steps)

### 1. Add HLC metadata to your ObjectBox Entity

```dart
import 'package:objectbox/objectbox.dart';

@Entity()
class WarehouseItem {
  int id = 0;
  String sku;
  String title;
  int stockQty;
  double price;

  // Fields required for CRDT conflict resolution
  int hlcTime = 0;
  int hlcCounter = 0;
  String originNodeId = '';

  WarehouseItem({
    this.id = 0,
    required this.sku,
    required this.title,
    this.stockQty = 0,
    this.price = 0.0,
  });
}
```

### 2. Initialize FreeBoxSync with your ObjectBox Store

In your app startup (e.g. `main.dart`):

```dart
import 'package:flutter/material.dart';
import 'package:freebox_sync/freebox_sync.dart';
import 'objectbox.g.dart'; // generated by objectbox_generator

late Store store;

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  // 1. Open ObjectBox Store
  store = await openStore();

  // 2. Start FreeBoxSync on the local LAN
  await FreeBoxSync.instance.initialize(
    store: store,
    nodeId: 'tablet_warehouse_01', // optional unique device ID
  );

  runApp(const MyApp());
}
```

### 3. Listen to local writes & broadcast deltas

```dart
final box = store.box<WarehouseItem>();

// Watch local database mutations
box.query().watch(triggerImmediately: false).listen((query) {
  final items = query.find();
  for (final item in items) {
    FreeBoxSync.instance.broadcastMutation(
      entityId: 101,
      objectId: item.id,
      deltaMask: 0b00000111,
      payload: Uint8List.fromList(item.title.codeUnits),
    );
  }
});
```

## Binary Wire Protocol (`OBXS`)

Each transaction frame is packed into an optimized 56-byte header:

```text
Offset  Size     Field         Description
0x00    4 bytes  MAGIC         0x4F425853 ("OBXS")
0x04    1 byte   VERSION       0x01
0x05    1 byte   FLAGS         Bit 0: Delta, Bit 1: Snapshot
0x06    1 byte   OPCODE        0x01: PUT, 0x02: DELETE, 0x03: BATCH
0x07    1 byte   RESERVED      64-bit alignment
0x08    8 bytes  NODE_HASH     uint64 hash of source device
0x10    8 bytes  TX_ID         Monotonic transaction sequence
0x18    8 bytes  HLC_PHYS      Physical timestamp (ms)
0x20    4 bytes  HLC_LOG       Logical counter
0x24    4 bytes  ENTITY_UID    ObjectBox Entity Schema UID
0x28    8 bytes  OBJECT_ID     Object 64-bit ID
0x30    4 bytes  DELTA_MASK    Bitmask of modified properties
0x34    4 bytes  PAYLOAD_LEN   Length of packed payload
0x38    N bytes  PAYLOAD       Zero-copy TLV delta values
```
